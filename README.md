# The Roofing Doctors Combined Website

This repository contains the new shared landing page for TheRoofingDrs.com and preserves the original residential and commercial website projects in separate folders when fully imported.

## Intended routing

- `/` shared landing page
- `/residential/` The Roof Doctors residential site
- `/commercial/` Commercial Roof Doctors site

The landing page and original app source must be integrated and tested before production deployment. No DNS or production changes are authorized by this repository import.
