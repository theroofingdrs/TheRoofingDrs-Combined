## Handling rules

- Incoming originals remain untouched. This document is an allocation map, not a move or deletion instruction.
- New website asset copies should use descriptive filenames and be optimized for web delivery.
- Existing approved website imagery must not be overwritten. In particular, retain the approved modified-bitumen image already used on the CRD Modified Bitumen page.
- Exclude social-media screenshots, promotional graphics with embedded contact copy, and images carrying legacy company marks unless a clean crop removes the mark without harming the subject.
- Do not present a roof-system image as proof of a specific installation method unless the visual actually supports that claim.
- For all project photography, avoid implying a named customer, address, warranty, or project outcome that has not been independently confirmed.

## Implementation sequence

1. Confirm existing page image references and asset naming conventions before adding any files.
2. Add optimized, descriptively named copies of the selected sources to the appropriate TRD or CRD public image directories. Keep all originals and review previews intact.
3. Update only the targeted page image references. Do not change copy, layout, metadata, routing, or unrelated assets.
4. Run the existing build and relevant checks. Open a pull request for review; do not deploy to Cloud Run as part of this image allocation change.
5. After merge and a separately authorized deployment, verify page rendering and image loading on the live domain.

## Review notes

The library contains a mix of residential, commercial, detail, progress, industry, and editorial images. The recommendations above are intended as page-fit assignments, not claims that each pictured building is a customer project. Before publishing identifiable third-party properties or branded buildings, confirm usage rights and avoid implying an endorsement or customer relationship.
